# PebbloScope Scholar — live

Public **deploy mirror** of PebbloScope Scholar (a branch of the PebbloScope visualization brand, Pebblous).

**Live:** https://joohaeng-pbls.github.io/PebbloScope-Scholar/

This repository contains only the **built, self-contained app** (`index.html`) served via GitHub Pages. The source code, build pipeline, and data corpora live in a separate **private** repository and are not published here.

`index.html` is a single self-contained file (all JS/CSS/data inlined) — it can also be downloaded and opened directly in a browser.
